Speed test seems low

  • Test on Wi-Fi first, then mobile data, to compare networks.
  • Close downloads and streaming apps during the test.
  • Servers near you can be busy; run the test again after a minute.
  • If Cloudflare rate-limits repeated tests, the app automatically uses a mirror.

Status-bar speed monitor

Enable Background monitor on the Network tab. Android requires an ongoing notification for this, so the live speed appears in the notification and its status-bar icon. Use the notification’s Stop action or the Network toggle to turn it off.

Widget

Settings → Add NetSpeed widget, or long-press your home screen → Widgets → NetSpeed. The widget updates while the background monitor is running.

Wi-Fi name or scanner is blank

Android requires location permission to read Wi-Fi names and nearby networks. Grant it from the Wi-Fi scanner screen. Location is used on-device only and never uploaded.

Ads and ad-free

A short rewarded video plays when a test starts; the test begins right after it. If no ad is available, the test starts immediately. Settings → Remove ads for 24 hours hides the banner and skips pre-rolls for a day.

Privacy

Read the privacy policy. No account is required and test history stays on your device.
